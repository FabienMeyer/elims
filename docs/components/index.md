# Components

ELIMS is split into two deployable applications and reusable Python packages.

- [Backend](../components/backend/index.md): FastAPI API, persistence integration, migrations, metrics, and operational endpoints.
- [Frontend](../components/frontend/index.md): React application, user journeys, design system, and accessibility.
- [Python packages](../packages/index.md): independently buildable domain and infrastructure libraries.

Component documentation is included from its source directory during the aggregate documentation build.
