# Roadmap

The roadmap is maintained through approved specifications rather than an unstructured feature list.

## Current foundation

- FastAPI backend and React frontend
- MariaDB persistence and Alembic migrations
- Reusable Python packages for CLI, communication, database, instruments, and utilities
- Automated quality, security, documentation, and container checks

## Next planning step

Capture each candidate capability in `docs/specifications/proposed/` using the canonical specification template.
