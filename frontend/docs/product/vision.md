# Frontend vision

The frontend presents laboratory workflows clearly, accessibly, and predictably while keeping domain logic and server state behind explicit boundaries.

## Responsibilities

- Guide users through approved workflows.
- Present validation and failure states without hiding uncertainty.
- Meet accessibility requirements for supported journeys.
- Keep server communication in feature-level adapters.

## Non-goals

- Reimplementing backend authorization or domain invariants
- Embedding environment-specific configuration in the bundle
- Shipping generated visual assets without provenance and review
