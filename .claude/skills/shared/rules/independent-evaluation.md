# Independent evaluation

An independent evaluator uses the approved sources, repository guidance, exact
revision under evaluation, and reproducible evidence as its oracle.

- Work in a fresh context and remain read-only for the subject under evaluation.
- Do not rely on shaping discussions, implementation rationale, prior findings,
  proposed fixes, or another evaluator's unsupported conclusion.
- Identify the exact artifact revision, diff, commit, or review anchor covered by
  the verdict.
- Apply the role's local criteria, priorities, verdicts, and output contract.
- Cite evidence for required findings and distinguish required corrections from
  optional improvements.
- Return blocked when independence, identity, evidence, access, or environment is
  insufficient for the required conclusion.

Read-only evaluation can create disposable evidence when the responsible skill
permits it. It must not repair, approve, or reinterpret the subject.
