# ASD-STE100-assisted writing

Use ASD-STE100 Issue 9 as the primary reference when the organization has supplied an authorized copy. This project guidance does not reproduce the controlled dictionary and does not certify compliance.

For all artifacts:

- Use one term for one concept and one meaning for each general word.
- Prefer approved vocabulary when the official standard is available.
- Permit necessary ELIMS and domain-specific technical names and technical verbs; define them when readers might not know them.
- Write short sentences with one main proposition where practical.
- Prefer active voice when it identifies responsibility more clearly.
- Avoid vague modifiers and qualifiers such as `appropriate`, `adequate`, `normally`, `user-friendly`, `quickly`, and `as needed` unless a measurable definition follows.
- Keep normative statements atomic. Do not combine independent obligations in one requirement.
- Preserve modal force: `must` is mandatory, `should` is recommended, and `may` grants permission.
- Preserve technical meaning when simplifying. Clarity must not remove a necessary condition, exception, or consequence.
- Use consistent identifiers and exact cross-references.

If the official standard or a qualified human review is unavailable, label the result `STE-assisted` or `STE not formally verified`. Never claim certified ASD-STE100 compliance from model review alone.
